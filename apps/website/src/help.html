Get Coinbox

Coinbox is a preview available through its setup guide. If someone has already set up a workspace for you, open the link they shared and enter your access code. A phone browser can open an existing workspace.

Open the setup guide ↗

Try a sample

  1. Open Import Inbox in the Personal book. A book keeps a set of accounts and transactions together.
  2. Choose Try sample bank statement. Select Add account for Sample checking. Check the column choices and select Review statement.
  3. Repeat with Try sample card statement and the Sample credit card account. Review both statements before saving either.
  4. Under Review card repayments, choose Match as transfer. Check the salary and bookshop purchase and select Save decisions.
  5. Open Overview. You should see ₹1,000 in net spending and ₹5,000 in income. In Ledger, open a statement reference to check the original row.

Statement formats

Start with CSV or Excel (.xls or .xlsx) for INR bank and credit card statements. Your file needs column headings, a date, a description and either an amount or separate debit and credit columns. Save your statement as a one-sheet Excel workbook.

Files can be up to 1 MiB. PDF import, where available, accepts unlocked statements with up to eight pages. Compare every extracted amount and date with the original. If Coinbox can’t read the table, export CSV or Excel from your bank.

In Match your columns, set the date order as it appears in the file. If the statement shows withdrawals or charges as positive numbers in one amount column, tick the matching option. Choose the running balance only if the statement has one.

Import a statement from email

  1. Download the statement attachment from your mail app and select it in Import Inbox. You can also download the original email as an .eml file.
  2. For an email file, choose it in Import Inbox and select Use attachment next to the statement.
  3. Check the columns, then select Review statement. Coinbox keeps the attachment once you select Review statement.

If Connect Gmail is available on your desktop, you can use it to find a statement. Google grants read-only mailbox access. Coinbox searches the label and optional sender you enter, then opens the message you choose.

Review warnings

Possible duplicate
Open both statement references. If they show the same transaction, skip the extra row.
Running balance doesn’t add up
Check the amounts, balance column, and whether the newest or oldest row comes first.
Possible card repayment
Match the bank withdrawal and card payment when they refer to the same repayment.

Choose Review later if you’re unsure. When you’re ready, Save decisions adds your selected transactions to the Ledger.

Reports and backups

In Reports, pick the April-to-March financial year. Export transactions and statement references for your accountant. Both files cover the full book. Use Statement coverage to see months that may need more statements.

If you see Encrypted backup, use it to download a copy of your workspace. Keep the passphrase separately. For a fresh desktop setup, choose Restore a backup and enter the passphrase used to create it. For a shared workspace, ask the person who set it up to restore the copy.

Where your statements are kept

This site uses sample data. When you use Coinbox on your own desktop, your imported statements and transactions are stored there in encrypted form. If you open a workspace someone set up for you, that workspace keeps the statements you import.

Encrypted backups need the original passphrase. Downloaded statements and CSV exports can be read by anyone with access to those files.

Get help

When reporting an issue, include what you clicked, what you expected, and which Coinbox version you used. Use the sample statements to demonstrate problems and leave personal statements, access codes, and passphrases out of the report.
